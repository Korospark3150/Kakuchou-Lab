# 拡張ラボ ホームページ 編集ガイド

## ファイルの役割
| ファイル | 役割 | 編集する? |
|---|---|---|
| `site-data.js` | **ページの文章・メンバー・プロジェクトなどの内容すべて** | ★ ここを編集 |
| `logo-data.js` | base64 のロゴを貼る場所(タブのアイコンとサイト内ロゴ) | ★ ロゴを入れるとき |
| `index.html` | ページの骨組み(見出しや図) | たまに |
| `style.css` | 色・大きさ・アニメーション | 見た目を変えるとき |
| `render.js` / `script.js` | 内容を表示する・動かすプログラム | 基本は触らない |
| `logo.svg` | ロゴ(base64 が空のときに使う) | 差し替えOK |

## よくある編集(すべて `site-data.js`)
- **メールアドレスを変える**: `lab.email` を書き換える(ページ内すべてに反映)
- **プロジェクトを増やす**: `projects` の `{ ... },` を1つコピーして貼る。`status` は `idea` `plan` `dev` `test` `done`
  - 進み具合を出す: `progress: 40` を書く(0〜100)
- **お知らせを追加**: `news` に `{ date: '2026-12-01', tag: 'お知らせ', title: '...', body: '...' },` を足す(新しい順に自動で並ぶ)
- **メンバーを追加・変更**: `members` を編集。`role` は `dev` / `test` / `design`
- **役割を増やす**: `roles` に `pm: 'リーダー'` のように足し、メンバーの `role` に `'pm'` と書く
- **沿革を進める**: `timeline` の「これから」を日付に変えて `done: true` を足す
- **FAQを増やす**: `faq` に `{ q: '質問', a: '答え' },` を足す(答えの中の `{email}` は自動でメールアドレスになる)

## 注意
- `{ ... },` のカンマや、`'` `"` を消さない。文字の中で `'` を使うときは全体を `"` で囲む。
- 変更したらブラウザで `index.html` を開き直す(更新ボタン)。表示が変なときは `site-data.js` のカンマ忘れを探す。
